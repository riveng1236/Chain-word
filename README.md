# Chain Word Online

## สำหรับริว: วิธีเอาเกมขึ้นออนไลน์แบบง่ายที่สุด

ไฟล์นี้เตรียม `render.yaml` สำหรับ Render ไว้ให้แล้ว

### สิ่งที่ต้องทำ
1. สร้างบัญชี GitHub
2. สร้าง Repository ใหม่
3. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน ZIP นี้เข้า Repository
4. เข้า Render แล้วเชื่อม GitHub
5. เลือก Repository นี้
6. เลือก Web Service
7. Render จะอ่าน `render.yaml` และตั้งค่า Node.js ให้
8. กด Deploy
9. รอจนขึ้นสถานะ Live แล้วกดลิงก์ `onrender.com`

หลังจากนั้นส่งลิงก์นั้นให้เพื่อนได้เลย

### ตั้งค่า AI ตรวจคำ (ทำทีหลังก็ได้)
ใน Render > Environment เพิ่ม:
`OPENAI_API_KEY`
แล้วใส่ API key ของผู้ดูแลเซิร์ฟเวอร์

ถ้าไม่ใส่ API key ระบบยังมีรายการคำสำรองสำหรับทดลองเล่น

### กติกา
- 2 คนออนไลน์ หรือเล่นคนเดียวกับ AI
- 15 วินาทีต่อเทิร์น
- 3 หัวใจ
- คำถัดไปต้องขึ้นต้นด้วยตัวอักษรสุดท้ายของคำก่อนหน้า
- คำที่เคยพยายามใช้จะถูกล็อกตลอดเกม แม้คำผิดและเสียหัวใจ
- คำไม่มีความหมาย/ไม่ใช่คำอังกฤษ = เสียหัวใจ
- คำซ้ำ = เสียหัวใจ
- รายการคำจะล้างเมื่อเกมจบและเริ่มเกมใหม่
